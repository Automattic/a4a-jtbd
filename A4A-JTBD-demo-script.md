# A4A JTBD Dashboard: Video Walkthrough Script

_High-level run-of-show. Each headline is a beat; bullets are talking points._

## 1. Open: what this is
- A living map of everything an agency can do in A4A, framed as Jobs To Be Done.
- 251 jobs today. Built out of the Design Den.

## 2. The three pillars
- Earn, Build, Grow: the high-level jobs agencies hire us for.
- Everything rolls up to these.

## 3. Three levels
- Pillar → Major function → Micro (CTA-level task).
- Click into a card to show the full job statement.

## 4. The job statement
- "When [situation], I want to [motivation], so I can [outcome]."
- Solution-free: focuses on the customer goal.

## 5. Filter by pillar
- Pick a pillar; canvas recenters on it.
- Shows how one pillar's functions branch out.

## 6. Filter by page
- Jump to a single product area (e.g., Marketplace).
- Mirrors the real product 1:1.

## 7. Filter by state
- Upcoming, New user, Intermittent, Redundant, Tier-gated.
- Auto-zooms to the biggest cluster (e.g., Tier-gated → Partner Directories).

## 8. Search
- Type a term; jump to a pillar; matches highlight, rest dims.

## 9. Evidence + validation
- Each job: draft → validated with data and customer quotes.
- Open the panel: add a source, mark validated.

## 10. Why it matters
- See every touchpoint in one place.
- Spot redundancy and streamline the IA.
- Every release/CTA adds a job: the map stays living.

## 11. Next steps
- Now on GitHub + Pages (live, shareable).
- Validate with 15k tickets + feedback; adopt ODI scoring.
- Segment by agency tier; sync to product.

## 12. Close
- Link to the live map. Call for feedback.
